# Valheim Client

Windows-клиент для автоматического обновления файлов Valheim и установленных модификаций с FTP-сервера.

Программа определяет расположение установленной игры, проверяет наличие необходимых файлов и директорий, при необходимости загружает актуальную версию клиента с сервера и после обновления запускает `valheim.exe`.

## Возможности

* автоматическое обнаружение папки Valheim;
* ручной выбор директории игры;
* сохранение последнего выбранного пути;
* подключение к FTP-серверу;
* рекурсивное получение структуры файлов обновления;
* проверка наличия необходимых файлов и директорий;
* загрузка отсутствующих файлов;
* полная повторная загрузка клиента;
* отображение текущего загружаемого файла;
* отображение прогресса обновления;
* автоматический запуск Valheim после обновления.

## Определение папки игры

Клиент поддерживает два режима.

### Автоматический

Программа проверяет доступные диски и ищет Valheim в нескольких стандартных расположениях Steam:

```text
Program Files (x86)\Steam\steamapps\common\Valheim
SteamLibrary\steamapps\common\Valheim
```

Если подходящая директория найдена, она используется автоматически.

### Ручной

Пользователь может выбрать папку игры через стандартный `FolderBrowserDialog`.

Выбранный путь сохраняется во временный файл:

```text
%TEMP%\ValheimGamePath.txt
```

При следующем запуске клиент пытается восстановить этот путь.

## Обновление клиента

После подключения к FTP программа начинает с директории:

```text
/LauncherFiles/
```

Клиент рекурсивно обходит её содержимое и формирует списки:

* основных директорий;
* вложенных директорий;
* файлов.

После этого выполняется проверка локальной установки.

Если отсутствует хотя бы один необходимый элемент, запускается загрузка клиента.

Перед загрузкой удаляются следующие директории:

```text
BepInEx
unstripped_corlib
doorstop_libs
```

Затем создаётся необходимая структура директорий и загружаются файлы с FTP-сервера.

## Полная перезагрузка

В интерфейсе предусмотрена возможность запустить полную загрузку файлов клиента.

В этом режиме программа подключается к FTP и выполняет загрузку содержимого сервера заново.

## Интерфейс

Приложение использует Windows Forms.

Основные элементы интерфейса:

* выбор режима определения папки игры;
* поле с путём к Valheim;
* кнопка выбора директории;
* кнопка запуска игры;
* индикатор прогресса;
* отображение текущего обрабатываемого файла;
* графический элемент интерфейса.

Обновление выполняется в отдельном `BackgroundWorker`, поэтому длительная загрузка файлов не должна блокировать основной интерфейс приложения.

## Конфигурация FTP

Параметры FTP-соединения в текущей версии находятся непосредственно в `Form1.cs`.

Основные параметры:

```csharp
private string FTP_SERVER = "...";
private int FTP_PORT = ...;
private string FTP_USER = "...";
private string FTP_PASSWORD = "...";
```

Для публичной или распространяемой версии приложения credentials лучше вынести из исходного кода и хранить отдельно от репозитория.

## Назначение проекта

Проект представляет собой специализированный launcher/updater для Valheim.

Основная задача клиента:

```text
Пользователь
    |
    v
Valheim Client
    |
    +-- поиск игры
    |
    +-- проверка файлов
    |
    +-- подключение к FTP
    |
    +-- обновление клиента
    |
    v
Valheim
```

Проект также демонстрирует работу с:

* Windows Forms;
* FTP-клиентом;
* файловой системой;
* рекурсивным обходом директорий;
* фоновой загрузкой данных;
* управлением процессами Windows;
* сохранением пользовательских настроек.

## Ограничения текущей версии

Проект является специализированным клиентом и не предназначен как универсальный игровой launcher.

В текущей реализации:

* FTP-параметры находятся в исходном коде;
* сторонние DLL подключаются через локальные пути;
* проверяется наличие файлов, но не их контрольные суммы;
* отсутствует дифференциальное обновление;
* загрузка не использует современный HTTP/CDN-подход;
* обработка ошибок FTP в некоторых местах сводится к отображению `MessageBox`;
* версия `.NET 6` уже не является актуальной для новых проектов.

## Статус

Проект является завершённой экспериментальной реализацией клиента обновления Valheim.

Исходный код сохранён в репозитории как пример собственного Windows launcher/updater с FTP-загрузкой.
